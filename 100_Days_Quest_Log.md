# 🗺️ 100 Days of DSA x Game Dev - The Quest Log

This is the ultimate syllabus. Every day is a new quest that teaches a core DSA concept by building a functional game mechanic or UI element using C++ and Raylib/OpenGL.

---

### **Arc 1: The Awakening (Days 1-10) - Arrays, Matrices, & Vectors**
*Goal: Understand 2D space, coordinates, and basic memory manipulation.*

- **Day 1: The Bouncing Ball** (Arrays, Variables, Basic Collision) ✅ *Cleared*
- **Day 2: The Magic Canvas (Part 1)** (2D Matrices, Mouse Tracking)
  - *Quest:* Build the foundation of a Paint App where the user can click to draw pixels on a grid.
- **Day 3: The Magic Canvas (Part 2) - The Flood** (DFS / BFS Algorithm)
  - *Quest:* Implement a "Bucket Fill" tool to color contiguous pixels using Depth-First Search.
- **Day 4: The Bouncing DVD Logo** (Math, Vectors, Screen Bounding)
  - *Quest:* Make a shape bounce around the screen perfectly hitting the corners.
- **Day 5: Snake Game Foundation** (Queues / Deques)
  - *Quest:* Create a snake that grows and follows its own tail.
- **Day 6: Snake Game - Apple Spawner** (Randomization, Collision)
  - *Quest:* Spawn apples avoiding the snake's body using efficient array lookups.
- **Day 7: The Starfield Simulation** (Structs, Arrays of Objects)
  - *Quest:* Render a 3D-looking starfield moving towards the player (Z-axis simulation).
- **Day 8: Flappy Bird - Gravity & Jump** (Velocity, Acceleration)
  - *Quest:* Implement realistic jumping physics and gravity vectors.
- **Day 9: Flappy Bird - Pipe Generation** (Sliding Window concept)
  - *Quest:* Generate infinite scrolling pipes dynamically.
- **Day 10: Arc 1 Boss Fight!** (Combine all concepts)
  - *Quest:* Build a mini-game combining the Snake and Bouncing Ball mechanics.

---

### **Arc 2: The Hero's Backpack (Days 11-20) - Linked Lists & HashMaps**
*Goal: Manage dynamic data, inventory systems, and fast lookups.*

- **Day 11: The Adventurer's Pouch** (Singly Linked Lists)
  - *Quest:* Build a dynamic inventory UI where items can be appended or dropped.
- **Day 12: Sorting the Loot** (Bubble & Insertion Sort)
  - *Quest:* Visually sort items in the inventory by value or rarity.
- **Day 13: The Undo Spell** (Stacks)
  - *Quest:* Add a "Ctrl+Z" feature to the Paint App using a Stack.
- **Day 14: The Quest Board** (Queues)
  - *Quest:* Build a UI that queues up incoming enemy waves or tasks.
- **Day 15: The Fast Travel Map** (Hash Maps / Dictionaries)
  - *Quest:* Create a system to instantly teleport to discovered locations using O(1) lookups.
- **Day 16: Drag and Drop Inventory** (Pointers & UI Logic)
  - *Quest:* Click and drag items between slots using C++ pointers.
- **Day 17: Crafting System** (Sets & Maps)
  - *Quest:* Combine items (e.g., Wood + Iron = Sword) by checking recipes in a HashMap.
- **Day 18: LLRU Cache (Recent Items)** (Doubly Linked List + HashMap)
  - *Quest:* Show the "Most Recently Used" items in a quick-access hotbar.
- **Day 19: The Dialogue Tree** (Basic Trees)
  - *Quest:* Build an NPC interaction UI where choices lead to different dialogues.
- **Day 20: Arc 2 Boss Fight!**
  - *Quest:* Full working Inventory UI with Crafting, Drag-n-Drop, and Sorting.

### **Arc 3: The Dungeon Crawler (Days 21-40) - Trees & Graphs**
- **Day 21-25:** BSP Trees for Dungeon Generation.
- **Day 26-30:** A* Pathfinding for Enemy AI.
